DECISIONS (recent — for UI design)
----------------------------------
- Product surface = web UI first; Telegram = NLP test harness only.
- Bring! sync = deprecated; own shopping UI is canonical.
- Each apartment = separate chat session (chat_id ≥ 100 in UI DB).
- Profile requires apartment on create; first real user: Sebastian @ Karl-Marx-Allee 5.
- Recipes live under Kitchen, not a top-level tab.
- Hub model: Kitchen and Bath are app launchers; timers are full-screen sub-views.
- Kitchen notes: shared sticky-note board per apartment (SQLite), markdown + @mentions.
- Bath sub-apps: cleaning (weekly reset), towels (use/wash log), medicine (expiry only).
- Timer done: sound + vibration + browser Notification (permission on start).
- Apartments: 13-char join code, owner accepts/kicks members (see docs/apartment_discussion.txt).
- Meal plans: per-apartment, persist across week navigation, auto-prune after 6 weeks.
